Foundations / Color

Color

Every surface and label in Mojo resolves to one of these variables. Toggle the switch in the header — this whole page is styled with them, nothing is hardcoded.

Values with a percentage are color-mix(in oklab, …) blends — 72% #1b2d45 → #fffffe reads as "72% of the first color mixed into the second." Click any card to copy its variable name.
